# Data Structures and Algorithms

This repository documents my study of data structures, algorithms, and common problem-solving patterns using Java.

Most problems come from *Cracking the Coding Interview*. I use ChatGPT as a study aid for hints, explanations, testing, code review, and complexity analysis. My focus is on understanding patterns and tradeoffs rather than memorizing solutions.

I hope this repository is also useful to others learning DSA or preparing for technical interviews.

## Common Problem-Solving Patterns

* Frequency counting
* Membership tracking
* Sort and scan
* Two pointers
* Sliding window
* Fast and slow pointers
* Prefix sums
* Binary search
* Stacks and queues
* Breadth-first search
* Depth-first search
* Backtracking
* Heaps and top-K
* Merge intervals
* Dynamic programming
* Greedy algorithms
* Graph traversal
* Topological sort
* Union-find
* Bit manipulation
